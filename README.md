# Room Booking Backend

Backend API untuk sistem peminjaman ruangan kampus.

## Deskripsi Sistem
Sistem Room Booking digunakan untuk mengelola peminjaman ruangan
oleh mahasiswa dan dosen secara terjadwal.

## Peran Backend
Backend bertugas untuk:
- Mengelola data ruangan
- Mengelola data pengguna
- Mengelola jadwal peminjaman
- Menyediakan API untuk frontend

## Rencana Teknologi
- Framework  : ASP.NET Core
- Database   : PostgreSQL
- Arsitektur : REST API

## Struktur Folder
- Controllers : Menangani request dari frontend
- Models      : Representasi data
- Services    : Logika bisnis
- Data        : Akses database
